Camera C64

Support

Write to support@camerac64.com, or, if you have a GitHub account, report a problem on GitHub. Please say which iPhone and which version of iOS you use.

The TV shows static instead of the camera

The app may not use the camera. Allow it in the Settings app, under Privacy & Security → Camera, then come back to Camera C64. Another app using the camera, such as a video call, also stops it until that app lets go.

Pictures are not saved to Photos

The app needs permission to add photos. Allow it in the Settings app, under Privacy & Security → Photos → Camera C64.

Setting up Send to C64

  1. Connect your Ultimate 64, C64 Ultimate or Ultimate-II+ to the same network as your iPhone.
  2. In the Ultimate's menu, turn on its web remote control (the REST API), and note its IP address, such as 192.168.1.64.
  3. In Camera C64, open Settings and enter that address, and the Ultimate's network password if you set one.
  4. After a shot, tap Send to C64. The first time, iOS asks to let the app find devices on your local network: allow it.

If the TV says NO NETWORK, allow Local Network for Camera C64 in the Settings app, under Privacy & Security → Local Network. If it says C64 NOT FOUND, check the address, and that the phone and the Ultimate are on the same network.

Using the C64 files

  • The .prg file shows the picture on a C64, or in an emulator such as VICE.
  • The .d64 file is a disk image holding that program: on a C64, type LOAD"*",8, then RUN.
  • Hires pictures also come as Art Studio files (.art), and multicolour pictures as Koala files (.kla), for C64 paint programs and tools.

The programs are made for PAL machines. A picture made for a black-and-white, amber or green monitor still holds colours, which may look odd on a colour TV.
