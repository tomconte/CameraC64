# C64 display programs

6502 code that runs on the C64: the viewers embedded in exported `.prg` files, one per graphics mode (standard bitmap modes, FLI/AFLI, interlace, NUFLI), in PAL and NTSC variants where timing matters.

The sources will be assembled in CI and bundled into the app as templates that the app fills with picture data. Nothing here yet; see milestones 1 and 4 in the [plan](../docs/REWRITE_PLAN.md).
